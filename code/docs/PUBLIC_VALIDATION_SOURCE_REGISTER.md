# Public validation-source register

This directory contains the project-authored validation note(s) for the case.
The note records the governing equations, scope boundary, and targeted checks.
Bibliographic sources are identified in `tests/_cross_validation/references.bib`
and in the note itself. Third-party book and article PDFs that were present in
the private working archive are intentionally not redistributed here; readers
should use the cited publisher or library records. This register is an index,
not a claim that the case has external calibration beyond the evidence tier in
`docs/case_validation_status.csv`.
