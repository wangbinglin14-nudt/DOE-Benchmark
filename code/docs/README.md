# 当前研究文档

本目录是公开代码、数据、研究方法和验证证据的技术文档入口。仓库导航见[根目录说明](../../README.md)。

| 用途 | 入口 |
|---|---|
| 安装、数据组装与复用 | [RESEARCH_REUSE.md](RESEARCH_REUSE.md) |
| 34个案例实现、出处和限制 | [CASE_EVIDENCE_INDEX.md](CASE_EVIDENCE_INDEX.md) |
| 案例证据等级和台账 | [CASE_VALIDATION_SUMMARY.md](CASE_VALIDATION_SUMMARY.md)、[CASE_LIBRARY_DATASHEET.md](CASE_LIBRARY_DATASHEET.md) |
| 论文主张、图表与数据对应 | [PAPER_CLAIM_TRACEABILITY.md](PAPER_CLAIM_TRACEABILITY.md)、[FIGURE_DATA_TRACEABILITY.md](FIGURE_DATA_TRACEABILITY.md) |
| 手稿源文件编译 | [MANUSCRIPT_BUILD.md](MANUSCRIPT_BUILD.md) |
| 冻结分析政策 | [STATISTICAL_ANALYSIS_PLAN.md](STATISTICAL_ANALYSIS_PLAN.md) |
| 完整运行流程 | [REPRODUCIBILITY.md](REPRODUCIBILITY.md) |
| 术语与常见问题 | [GLOSSARY.md](GLOSSARY.md)、[FAQ.md](FAQ.md) |

`case_*.csv` 和 `case_evidence_manifest.json` 是当前证据及测试台账，保留供校验程序使用。
统计分析政策、已发生的方法修正、验证限制和实验记录均保留；内部工作计划不属于公开文档。

图表数据、补充表格和冻结协议在仓库的 `manuscripts/`，研究命令在 `code/` 执行。目录说明见[仓库布局](overview/WORKSPACE_LAYOUT.md)。
