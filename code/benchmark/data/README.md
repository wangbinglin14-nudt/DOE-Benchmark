# Benchmark data

These files are the active machine-readable inputs used by the benchmark and
paper-generation scripts.

| File | Role |
|---|---|
| `sobol_data.csv` | Original compact Sobol reference data. |
| `sobol_cross_validation.json` | Historical cross-validation reference retained for comparison. |
| `sobol_corrected_full_current_source.json` | Canonical current-source Sobol artifact used by the Supplementary Information generator. |

Candidate, screening and partial high-sample Sobol diagnostics are retained
under `_archive_20260909/sobol-diagnostics/benchmark/data/`. They are not
current manuscript inputs. The archive README and SHA-256 manifest record
their original locations.
